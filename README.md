# Prelive Releases

Public download host for [Prelive](https://prelive.ai) installers.

The **Prelive OBS Setup** app configures OBS in one click — docks, stream output, and the aggregated chat overlay. Download it from https://prelive.ai/download/obs (or the Releases tab here).

Source for Prelive itself is maintained in a private repository; this repo holds published binaries only.
